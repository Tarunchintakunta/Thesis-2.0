\chapter{Evaluation}

\section{Data provenance}

All committed metrics are from the \textbf{local S3 simulator} (\texttt{DRY\_RUN=1}).
Authoritative artefacts:
\texttt{s3-predictive-optimization/results/data/\{pilot,baseline,improved\}\_results.json}.
No live S3 Inventory, Cost Explorer, CloudWatch, or Wilcoxon campaign is claimed.

Forecast evaluation uses a \textbf{temporal holdout}
(\texttt{eval\_protocol=temporal\_holdout}): Prophet and naive persistence are fit on the
prefix of the synthetic daily-cost series and scored on the held-out suffix.
An earlier protocol compared both models to a synthetic growing series while costs
were rounded to four decimals (flattening sub-cent series); that protocol is withdrawn.

\section{What is and is not evidenced}

\begin{itemize}
    \item \textbf{Evidenced:} recommendation + forecast + savings pipeline on synthetic
          workloads; naive persistence baseline (Beck et al.); local list-price savings;
          holdout \texttt{beats\_naive=true} on pilot, baseline, and improved.
    \item \textbf{Not evidenced:} live AWS FinOps RQ, Inventory/Boto3 metadata collector,
          Cost Explorer cross-check, multi-workload Wilcoxon.
\end{itemize}
