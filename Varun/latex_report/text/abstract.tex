\chapter*{Abstract}
This thesis designs a predictive storage-class recommendation and cost-forecasting framework for Amazon~S3, combining a TierBase-inspired rule recommender, an XGBoost allocator, a Prophet forecaster with a naive persistence baseline (Beck et al.), and a delta-pricing savings estimator.

Committed dry-run experiments use the \textbf{local simulator} (\texttt{DRY\_RUN=1}) with synthetic access logs. Authoritative numbers are in \texttt{results/data/\{pilot,baseline,improved\}\_results.json} under a temporal-holdout forecast protocol. On those runs, simulated monthly savings reach up to $\sim$57\% versus an unoptimized baseline; Prophet \textbf{beats} naive on all three committed arms (pilot/baseline/improved MAPE $0.016$\% / $0.006$\% / $0.231$\% vs naive $0.44$\%). ML allocation accuracy on the improved run is $0.178$.

A separate \textbf{live lite} AWS probe (2026-09-20, \texttt{eu-west-1}; artefacts under \texttt{results/live/live\_lite\_summary.json}) measured PUT/GET latency on 24 objects $\times$ STANDARD vs STANDARD\_IA, reached Cost Explorer and CloudWatch APIs, and reported paired Wilcoxon significance on modeled storage cost and live latency ($n{=}24$).

Three full live evaluations (\texttt{evaluation\_r1}--\texttt{r3}; aggregate \texttt{BASELINE\_COMPARE.md}) run the CA2 three-workload Wilcoxon protocol versus Lifecycle and Intelligent-Tiering. \texttt{static\_archival} and \texttt{mixed\_access} beat both natives; \texttt{high\_churn} shows little/no improvement versus Lifecycle (non-significant Wilcoxon) --- retained as a negative/null result. Each evaluation meets the two-of-three gate. Trial/list-price costs are not CE-settled production bills; e1--e3 summaries disclose rebuild-from-log identity across evaluation folders.
