\chapter*{Abstract}
This thesis designs a predictive storage-class recommendation and cost-forecasting framework for Amazon~S3, combining a TierBase-inspired rule recommender, an XGBoost allocator, a Prophet forecaster with a naive persistence baseline (Beck et al.), and a delta-pricing savings estimator.

All committed experiments run in the \textbf{local simulator} (\texttt{DRY\_RUN=1}) with synthetic access logs. Authoritative numbers are in \texttt{results/data/\{pilot,baseline,improved\}\_results.json}. On those runs, simulated monthly savings reach up to $\sim$57\% versus an unoptimized baseline, but Prophet does \textbf{not} beat the naive forecast (\texttt{beats\_naive=false}; MAPE $\approx$21\%), and ML allocation accuracy on the improved run is only $0.178$. No live S3 Inventory, Cost Explorer, CloudWatch, or Wilcoxon campaign is claimed. Live AWS evaluation remains a CA2 residual under the alignment-first gate.
