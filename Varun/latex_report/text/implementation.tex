\chapter{Implementation}

The implementation lives under \texttt{Varun/s3-predictive-optimization/} and is driven by
\texttt{make pilot|baseline|improved} with \texttt{DRY\_RUN=1} by default.

\begin{itemize}
    \item \texttt{src/runner/experiment.py} --- orchestrates workload, recommend, forecast
          (holdout), savings, and evaluation; writes
          \texttt{results/data/*\_results.json}.
    \item \texttt{src/forecasting/} --- Prophet wrapper and Beck naive persistence baseline.
    \item \texttt{src/recommendation/} --- rules + XGBoost.
    \item \texttt{src/savings/} + \texttt{src/pricing/} --- list-price estimator (not live
          Pricing API).
    \item \texttt{tests/} --- pytest suite including holdout hygiene tests.
    \item \texttt{terraform/} --- temporary eval stack applied for the 2026-09-20
          live lite probe, then \textbf{destroyed} (8 resources; empty state retained).
    \item \texttt{scripts/live\_lite\_round.py} --- measured S3/CE/CW/Wilcoxon lite probe
          writing \texttt{results/live/live\_lite\_\{summary,raw\}.json}.
    \item \texttt{src/metadata/} --- lite JSON parser, S3 Inventory CSV parser, Boto3
          \texttt{ListObjectsV2} listing (injected client; moto-tested). Not a live Inventory job.
    \item \texttt{analysis/statistics.py} --- live-lite Wilcoxon re-export plus local
          three-workload Wilcoxon vs Lifecycle / Intelligent-Tiering.
\end{itemize}

The lite Wilcoxon calls are probe-scoped ($n{=}24$). The three-workload protocol uses
simulator trial-buckets, not live S3.
