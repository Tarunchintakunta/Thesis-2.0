\chapter{Conclusion}
This work delivers a reproducible \textbf{local} S3 FinOps artefact: rule and ML recommenders, Prophet versus naive forecasting, and a savings estimator driven by local list prices. Committed dry-run results support a simulated cost-reduction narrative under synthetic workloads, but they do \textbf{not} validate a live AWS research question.

\textbf{Evidence locked to JSON.} Pilot / baseline / improved runs report allocation accuracies $0.320$ / $0.504$ / $0.178$, forecast MAPE $\approx 21\%$, and \texttt{beats\_naive=false} throughout. Simulated savings percentages ($42\%$, $21\%$, $57\%$) must not be read as Cost Explorer or production bills.

\textbf{What remains.} Live metadata collection, multi-workload Wilcoxon testing, and CloudWatch/Cost Explorer cross-checks are unimplemented. Until those exist, CA2 research alignment stays below 100\% and the project is not SUBMIT-READY. Boilerplate ``cloud-native distributed state'' filler is intentionally omitted; claims track the dry-run artefact only.
