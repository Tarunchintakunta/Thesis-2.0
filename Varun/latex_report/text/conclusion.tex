\chapter{Conclusion}
This work delivers a reproducible \textbf{local} S3 FinOps artefact: rule and ML recommenders, Prophet versus naive forecasting (temporal holdout), and a savings estimator driven by local list prices. Committed dry-run results support a simulated cost-reduction narrative under synthetic workloads, but they do \textbf{not} validate a live AWS research question.

\textbf{Evidence locked to JSON.} Pilot / baseline / improved allocation accuracies $0.320$ / $0.504$ / $0.178$; holdout MAPE $0.016$ / $0.006$ / $0.231$ versus naive $0.44$; \texttt{beats\_naive=true} on all three arms. Simulated savings percentages ($42\%$, $21\%$, $57\%$) must not be read as Cost Explorer or production bills.

\textbf{What remains.} Live metadata collection, multi-workload Wilcoxon testing, and CloudWatch/Cost Explorer cross-checks are unimplemented. Those are the sole hard residual to 100\% CA2 alignment; the project is not SUBMIT-READY until a gated live campaign exists. Claims track the dry-run artefact only.
