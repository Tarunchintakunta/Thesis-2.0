Research Problem Background
Organizations are relying on cloud computing as the main storage and management platform for huge and
massive data sets. Amazon S3 is among the most widely used cloud storage object storage solutions that are
available, with features such as scalability, durability, and compatibility with cloud-native applications. As
more companies have increasingly embraced data intensive applications that run on the cloud, storage costs
are a huge operating expense. This efficiency of data storage and making the data available has thus become
a major challenge for cloud administrators and FinOps teams.

Amazon S3 has several storage classes: Standard, Standard-Infrequent Access (Standard-IA), Glacier Instant
Retrieval, Glacier Flexible Retrieval, and Glacier Deep Archive. Each of these storage classes has a unique
compromise of storage cost, retrieval speed and accessibility. The appropriate storage class for each object
may result in cost savings. But, there are so many that are still storing data in expensive tiers for more than
they need to, which results in unnecessary resource utilization and costs (Liu et al., 2025).

Amazon S3 Lifecycle Policies and Amazon S3 Intelligent-Tiering are AWS solutions to this problem. You can
use Lifecycle Policies to move objects between storage classes based on a set of rules, such as object age, or
Intelligent-Tiering automates the movement of objects between storage classes, based on access patterns
that it detects. Most of these solutions are rule-based or reactive, and can help to save costs. Intelligent-
Tiering only makes decisions after there has been a change in access pattern, while Lifecycle Policies do not
take into account future access patterns.

Recent research in the use of intelligent approaches for placement and optimization of storage is discussed.
This study has relied mainly on the research conducted by (Yang et al., 2025) on using machine learning
technologies to enhance storage efficiency and decrease operational costs in warehouse-scale computing
environments by making intelligent decisions in storage placement. Similarly, (Tu et al., 2025) investigated
intelligent storage tiering mechanisms that aim to achieve high efficiency of storage hierarchy by making
optimal decisions on data placement. Moreover, (Shen et al., 2025) suggested a new storage architecture
called TierBase, which is cost-optimized and performance-oriented, by dynamically adjusting storage tier
placement and optimizing data based on the workload.

Existing works prove the merits of intelligent storage placement, storage tiering, and workload-driven cost
optimization, but do not particularly focus on providing Amazon S3 storage-class recommendation, storage
cost forecasting and optimization savings estimation in one AWS-native framework, respectively ( Yang et al.,
2025; Liu et al., 2025; Tu et al., 2025; Shen et al., 2025). This is why a research gap exists in the field of
developing a single solution for technical storage solutions optimization and financial forecasting for proactive
cloud storage management through FinOps.

Therefore, an AWS-native framework is needed to support intelligent storage-class recommendation, storage
cost optimization, and estimation of storage costs in the future. This research introduces a Predictive Storage
Cost Optimization Framework for Amazon S3 that uses object characteristics and storage usage information
to suggest appropriate storage classes, predict future storage costs and calculate the predicted savings. The
proposed framework aims to be more efficient with the storage, establish FinOps practices and provide
organizations with visibility of the cost of their cloud storage.
Research Question
What is the impact of implementing an integrated predictive storage cost optimization framework with
intelligent storage-class recommendations, cost prediction and optimization savings estimation on storage
utilization efficiency, cloud storage cost savings and proactive cloud FinOps-optimized decision making as
compared to native AWS solutions?



Justification
The cloud storage management in a cloud environment like Amazon S3 is a big challenge in cloud computing
because of the escalating cost of cloud storage management. With the massive amount of data being created
and stored in big organizations, storage costs now make up a significant portion of the cost of operating a
cloud. AWS offers storage optimisation features like Lifecycle Policies and Intelligent-Tiering, but these are
rule based or reactive and don't offer much in terms of predicting future storage costs, or estimating the costs
of optimisation choices (Yang et al., 2025). This makes it hard for organisations to make forward-thinking,
cost-effective decisions about storage that optimise cost, performance and accessibility.

The proposed research is feasible and practical as it can be done by leveraging existing AWS technologies like
Amazon S3, storage-class management features, AWS pricing information, Python, and the AWS SDK. The
framework can be deployed and evaluated in a real AWS environment, allowing for a collection of operational
data to be captured in a realistic environment, rather than just relying on simulated scenarios. This way, the
results can be used directly in practical cloud storage setups, and successfully tested with experiments.

The effectiveness of the proposed framework can be measured by objective and quantifiable metrics like a
reduction in storage cost, estimated cost savings, storage utilization efficiency, storage-class allocation
accuracy, and effectiveness of storage optimization recommendations. These metrics offer an objective,
quantitative means to assess the effectiveness of the framework and its ability to offer value over current
AWS-native storage optimization options.

The research is valuable due to the rising importance of cloud cost optimization and FinOps in the minds of
organizations looking to get the most out of their cloud investments. Recently, machine learning techniques
have also been emphasized for enhancing the allocation and optimization of cloud resources, (Bodra, 2025).
The proposed framework can aid in better understanding the storage spend, detect storage optimization
opportunities, and predict future storage expenses, enabling more data-driven and informed cloud financial
management practices. The results can contribute to organizations to optimize their budgeting, resource
planning, cloud governance and ensure that they achieve adequate data accessibility and performance at
data retrieval time.

The innovation of this research is the ability to integrate the three technologies – storage-class
recommendation, storage cost estimation, and optimization saving estimation – within a single AWS-native
framework. AWS storage optimization and storage cost reporting are solved by separate existing services like
Lifecycle Policies, Intelligent-Tiering, and Cost Explorer. The proposed framework, however, combines these
to provide one decision support system for managing cloud storage. This is an extension of existing
knowledge, as it proposes a new way to find a solution to the synergy of intelligent storage optimization and
financial forecasting for better technical and financial results in Cloud Computing environments.

The research also has an ethical aspect since it does not deal with sensitive personal data, human participants
or high risk activities. All experimentation will be done with cloud storage resources and operational data
created in a controlled AWS environment. Thus, the study poses very few ethical issues and provides benefits
to organizations using cloud technologies.
The proposed framework will leverage Amazon S3 object metadata that is gathered via the AWS SDK (Boto3),
such as object size, storage class, object age, and access frequency. The storage usage patterns will be
analysed by a rule-based and machine learning-based recommendation engine, and suitable storage classes
will be recommended. Storage usage and price history will be provided to create storage cost forecasts and
estimate optimisation savings. The framework will be tested in a controlled AWS environment and measured
by storage cost savings, storage utilisation efficiency, accuracy in storage-class allocation and estimated
storage optimisation savings.

Specific Items to Be Addressed
Item #1: Create a metadata collection module with the AWS SDK (Boto3) that will gather the attributes of
objects stored on Amazon S3 such as object size, storage class, object age, and access frequency, and store
the data as a structured dataset for use with S3 storage analysis and cost optimization.
Item #2: Build an intelligent storage-class recommendation engine that uses metadata from S3 objects to
make intelligent recommendations using a rules-based approach and data-driven methods to determine the
most cost effective storage class for specific object characteristics, access patterns and storage needs.
Item #3: Develop a predictive storage cost forecasting feature based on historical storage usage and pricing
information to estimate the cost of storage into the future and the potential optimisation savings available
per storage class.
Item #4: Assess the effectiveness of the proposed framework by comparing storage-class allocation accuracy,
storage utilisation efficiency, storage cost reduction, and estimated optimisation savings with the current
storage configurations, and existing AWS-native solutions.
Item #5: Deploy and test the full solution in a controlled AWS environment and evaluate how effective the
solution is in supporting cloud storage optimisation and proactive FinOps decision-making versus the current
AWS native offerings.
