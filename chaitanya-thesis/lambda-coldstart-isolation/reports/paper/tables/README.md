# tables/

Generated by `scripts/analyse.py` (and `scripts/analyse_proxy.py`), one folder per data source:

* `live/` - real results, after the AWS campaign (not there yet)
* `mock/` - **SYNTHETIC** pipeline test output; the numbers come from placeholder parameters and mean nothing about Lambda
* `proxy/`, `proxy_dev/` - local init-proxy benchmark (real measurement of process start, not Lambda)

Each folder has `decision_matrix.md/.csv`, `hypotheses.json` (tests, Holm-adjusted
p-values, effect sizes), `summary_by_cell.csv` (p50/p95/p99 per cell) and
`phase_a_baseline_style.csv`.
