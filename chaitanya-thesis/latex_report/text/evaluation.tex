\textbf{Interpretation (proxy only):} On this host, dependency bloat dominates language
choice for process-start cost. Optimised packages cluster within $\approx$16\,ms of each
other (Python 20.9, Node.js 30.4, Java 37.2). These magnitudes do \textbf{not} transfer to
AWS Lambda: the proxy has no Firecracker micro-VM, no S3 code download, and no Lambda
runtime API handshake.
