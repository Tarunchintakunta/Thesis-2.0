\section{Conclusion and Future Work}
\label{sec:Conclusion}
%% ==================

Formal CA2 asks whether MHSA-TDL improves cluster-health / failure prediction on Google Cluster Trace versus hybrid and traditional monitors, under Acc/Prec/Rec/F1/ROC-AUC/latency. This artefact provides an MHSA implementation, a five-seed synthetic harness with that formal metric suite and classical RF/KNN/SVM monitors, and an explicit GCT absence gate (\texttt{DATA\_GAPS.md}, \texttt{gct\_loader.py}). It does \textbf{not} yet answer the formal research question: synthetic scores are development evidence only.

\textbf{Remaining blockers to formal alignment:}
\begin{itemize}
  \item Ingest Google Cluster Trace (2011 and/or 2019) per \texttt{DATA\_GAPS.md} and implement the reviewed usage$\leftrightarrow$event window join.
  \item Re-run the metric suite with \texttt{--dataset gct}; report confusion-matrix FN/FP analysis on GCT splits.
  \item Complete Aldomi-style~\cite{Aldomi26} hybrid comparison on the same GCT features (beyond scaffold RF/KNN/SVM).
\end{itemize}

AWS live deploy is \textbf{not} required for alignment. Optional Colab/EC2 GPU training remains a resource choice after GCT data exists.
