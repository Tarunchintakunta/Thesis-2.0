\section{Implementation}
\label{sec:Implementation}
%% ==============================

The system is implemented in Python 3 with PyTorch. Key modules:

\begin{itemize}
  \item \texttt{src/data/telemetry\_simulator.py} -- synthetic telemetry generator described in Section~\ref{sec:Methodology}.
  \item \texttt{src/models/mhsa\_model.py} -- \texttt{SharedBackbone}, \texttt{MHSAPerHead} (baseline), \texttt{MHSAFused} (improved), and the \texttt{CrossHeadFusion} layer.
  \item \texttt{src/models/baseline.py} -- \texttt{ThresholdBaseline}, the reactive monitoring comparison.
  \item \texttt{scripts/train\_and\_evaluate.py} -- trains and evaluates all three approaches across 3 seeds, writes \texttt{results/results\_per\_seed.csv} and \texttt{results/results\_summary.csv}, and exports the trained \texttt{MHSAFused} weights to \texttt{models/mhsa\_fused.pt} for deployment.
  \item \texttt{src/lambda\_handler/app.py} -- an AWS Lambda handler that loads the exported model and runs real inference (not a mock) over telemetry records arriving on a Kinesis stream, in a 30-day rolling window per node.
  \item \texttt{template.yaml} -- AWS SAM template provisioning the Kinesis stream and Lambda function.
  \item \texttt{.github/workflows/deploy.yml} -- CI pipeline that runs the training/evaluation script and, on push to \texttt{main}, deploys the SAM stack to the configured AWS region using repository secrets.
\end{itemize}

Running \texttt{python scripts/train\_and\_evaluate.py} reproduces every number in Section~\ref{sec:Evaluation} from scratch (no external dataset dependency, since telemetry is synthetically generated with a fixed seed).
