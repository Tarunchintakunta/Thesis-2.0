\begin{abstract}

Cloud-native computing has revolutionized application deployment, yet the distributed nature of cloud environments presents significant cybersecurity challenges, particularly for intrusion detection systems (IDS). Traditional centralized IDS architectures face scalability limitations, privacy concerns, and excessive communication overhead when deployed across multi-tenant cloud infrastructures. This research presents SecureFL-IDS, a privacy-preserving federated intrusion detection framework designed specifically for cloud-native environments.

SecureFL-IDS addresses these challenges by combining Federated Learning (FL) with Differential Privacy (DP), enabling collaborative threat detection across distributed cloud tenants without sharing sensitive network traffic data. The framework implements a baseline replication of the privacy-preserving FL-IDS approach proposed by \citet{saklani2026privacy} and an improved variant with adaptive differential privacy, top-k gradient compression, and a hybrid CNN-LSTM architecture.

\textbf{Committed results.} Synthetic PoC (\texttt{results/comparison/results.json}): centralised accuracy $0.7975$; baseline FL $0.793$ (F1 $\approx 0.019$); improved FL $0.800$ (F1 $0.0$); communication $1.83$ vs $3.12$~MB/round. Real UNSW-NB15 training-partition stratified sample (\texttt{results/unsw\_real/results.json}): centralised $0.9452$ / F1 $0.9603$; baseline FL $0.8934$ / F1 $0.9262$; improved FL $0.6800$ / F1 $0.8095$. Synthetic near-zero F1 and improved-arm underperformance on the real sample are reported honestly.

The evaluated artefact runs as a \textbf{local simulation only}. Docker, Kubernetes, and live AWS deployments are \emph{not} claimed as executed; a Terraform scaffold under \texttt{securefl-ids/terraform/} exists but has \textbf{not} been applied.

This work contributes a reproducible FL+DP IDS artefact with a centralised comparator and a real training-partition sample campaign. Live cloud-native deployment remains the sole open CA2 residual.

\end{abstract}

\textbf{Keywords:} Federated Learning, Intrusion Detection, Differential Privacy, Cloud Security, Privacy-Preserving Machine Learning, Cloud-Native Security
