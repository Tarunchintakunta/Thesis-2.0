\begin{abstract}

Cloud-native computing has revolutionized application deployment, yet the distributed nature of cloud environments presents significant cybersecurity challenges, particularly for intrusion detection systems (IDS). Traditional centralized IDS architectures face scalability limitations, privacy concerns, and excessive communication overhead when deployed across multi-tenant cloud infrastructures. This research presents SecureFL-IDS, a privacy-preserving federated intrusion detection framework designed specifically for cloud-native environments.

SecureFL-IDS addresses these challenges by combining Federated Learning (FL) with Differential Privacy (DP), enabling collaborative threat detection across distributed cloud tenants without sharing sensitive network traffic data. The framework implements a baseline replication of the privacy-preserving FL-IDS approach proposed by \citet{saklani2026privacy} and an improved variant with adaptive differential privacy, top-k gradient compression, and a hybrid CNN-LSTM architecture.

\textbf{Committed proof-of-concept results} (local multi-process simulation, synthetic UNSW-NB15-derived data, 30 rounds, 5 clients), recorded in \texttt{results/comparison/results.json}, are: baseline accuracy $0.793$ with F1-score $\approx 0.019$; improved accuracy $0.800$ with F1-score $0.0$; average communication $1.83$~MB/round (baseline) versus $3.12$~MB/round (improved). The near-zero F1 scores reflect majority-class collapse on the synthetic feature space and are reported honestly; they are \emph{not} literature-level detection performance. Saklani et al.\ report $\approx 91.8\%$ accuracy on full UNSW-NB15; such figures are treated here as baseline-paper reference points, not as results of this PoC.

The evaluated artefact runs as a \textbf{local simulation only}. Docker, Kubernetes, and live AWS (e.g.\ ECS) deployments are \emph{not} claimed as executed; a Terraform scaffold under \texttt{securefl-ids/terraform/} exists but has \textbf{not} been applied. Privacy mechanisms follow ($\epsilon$, $\delta$)-differential privacy with target $\epsilon = 1.0$ and $\delta = 10^{-5}$ in the implemented code paths.

This work contributes a reproducible FL+DP IDS artefact and an honest PoC evaluation. Full-dataset training, a centralised IDS comparator, and live cloud-native deployment remain future work required for CA2 completion.

\end{abstract}

\textbf{Keywords:} Federated Learning, Intrusion Detection, Differential Privacy, Cloud Security, Privacy-Preserving Machine Learning, Cloud-Native Security
