\section{Conclusion}
\label{sec:conclusion}

\subsection{Summary of Contributions}

This research presented SecureFL-IDS, a privacy-preserving federated intrusion detection framework for cloud-native environments. The work makes four primary contributions:

\begin{enumerate}
    \item \textbf{Baseline Replication:} Faithful implementation of the PP-FL-DP-IDS approach by \citet{saklani2026privacy}, achieving 91.2\% accuracy and establishing a reproducible baseline for comparison.
    
    \item \textbf{Enhanced Framework:} SecureFL-IDS introduces adaptive differential privacy, communication-efficient aggregation via top-k compression, and CNN-LSTM hybrid architecture, improving accuracy to 93.7\% (+2.5\%), reducing communication costs by 45.2\%, and accelerating convergence by 30\%.
    
    \item \textbf{Comprehensive Evaluation:} Systematic experimental analysis on the UNSW-NB15 benchmark under realistic non-IID data distribution, demonstrating statistically significant improvements across detection performance, privacy preservation, and resource efficiency.
    
    \item \textbf{Open-Source Artefact:} Complete implementation with modular codebase, local simulation environment, unit tests, experiment scripts, and deployment templates for reproducibility and practical deployment.
\end{enumerate}

\subsection{Research Question Answered}

The primary research question asked:

\begin{quote}
\textit{What is the effect of combining Federated Learning with Differential Privacy and communication-efficient aggregation on the accuracy, privacy preservation, and resource efficiency of cloud-native intrusion detection systems?}
\end{quote}

The experimental results provide a clear answer:

\begin{itemize}
    \item \textbf{Accuracy:} Adaptive privacy and enhanced neural architectures improve detection accuracy by 2.5\% without compromising privacy guarantees.
    
    \item \textbf{Privacy:} ($\epsilon=1.0$, $\delta=10^{-5}$)-differential privacy provides strong protection against membership inference attacks with only ~2-3\% accuracy cost.
    
    \item \textbf{Communication Efficiency:} Top-k gradient compression reduces bandwidth by 45\% while maintaining detection performance, making federated IDS practical for bandwidth-constrained cloud-edge scenarios.
    
    \item \textbf{Convergence:} Quality-weighted aggregation accelerates convergence by 30\%, reducing training time and enabling faster adaptation to evolving threats.
\end{itemize}

SecureFL-IDS demonstrates that federated learning can effectively address the privacy-utility-efficiency trilemma in cloud-native intrusion detection.

\subsection{Limitations and Constraints}

This research has several limitations that should be acknowledged:

\begin{enumerate}
    \item \textbf{Evaluation Scope:} Experiments use local simulation on a single dataset (UNSW-NB15). Real-world validation on distributed cloud infrastructure with multiple organizations remains future work.
    
    \item \textbf{Threat Model:} Assumes honest-but-curious participants without Byzantine behavior. Production deployment requires additional defenses (e.g., robust aggregation, anomaly detection).
    
    \item \textbf{Attack Taxonomy:} Current implementation focuses on binary classification. Extending to fine-grained multi-class attack detection (9+ categories) and zero-day threats would enhance practical utility.
    
    \item \textbf{Dynamic Environments:} Static federated rounds do not adapt to concept drift or evolving attack patterns. Continuous learning mechanisms are needed for long-term deployment.
    
    \item \textbf{Computational Overhead:} CNN-LSTM architecture increases training time by ~15\%. Resource-constrained edge devices may require model compression or quantization.
\end{enumerate}

\subsection{Future Work}

Several promising directions for extending this research include:

\subsubsection{Byzantine Resilience}

Integrate robust aggregation methods (Krum, Trimmed Mean, median aggregation) to defend against malicious clients attempting model poisoning attacks. This would move beyond the honest-but-curious threat model to address adversarial federated learning scenarios.

\subsubsection{Asynchronous Federated Learning}

Implement asynchronous aggregation protocols to tolerate stragglers (slow or unreliable clients) without blocking global model updates. This improves system responsiveness and fault tolerance in dynamic cloud environments.

\subsubsection{Personalized Models}

Explore personalized federated learning where each client maintains a local model fine-tuned to its specific traffic patterns while still benefiting from global knowledge. This could improve detection of tenant-specific attack vectors.

\subsubsection{Multi-Attack Classification}

Extend from binary (normal vs attack) to multi-class classification across 9+ attack categories (DoS, Reconnaissance, Exploits, etc.). This provides finer-grained threat intelligence for incident response.

\subsubsection{Zero-Day Detection}

Integrate anomaly detection layers (autoencoders, isolation forests) to identify previously unseen attack patterns not present in training data. This addresses the limitation of supervised learning's reliance on labeled historical attacks.

\subsubsection{Continuous Learning}

Implement online learning mechanisms to adapt the federated model to concept drift and evolving attack strategies without periodic retraining from scratch. This is critical for long-term production deployment.

\subsubsection{Secure Aggregation}

Apply cryptographic secure aggregation protocols (e.g., secure multi-party computation) to provide information-theoretic privacy guarantees beyond differential privacy's probabilistic protection. This addresses sophisticated gradient inversion attacks.

\subsubsection{Cross-Dataset Evaluation}

Validate SecureFL-IDS on additional IDS benchmarks (CIC-IDS2017, TON\_IoT, Edge-IIoTset) to assess generalization across different network environments and attack distributions.

\subsubsection{Real-World Deployment}

Pilot SecureFL-IDS with actual cloud providers or enterprises to evaluate performance under real network conditions, operational constraints, and regulatory requirements.

\subsubsection{Explainability}

Integrate explainable AI techniques (SHAP, LIME, attention mechanisms) to provide interpretable detection decisions, crucial for security analysts investigating flagged traffic.

\subsection{Closing Remarks}

Cloud-native computing has revolutionized application deployment but introduced new security challenges that traditional centralized defenses struggle to address. This research demonstrates that federated learning with differential privacy and communication optimization can provide an effective solution, enabling collaborative intrusion detection that respects data privacy, scales to distributed infrastructures, and achieves competitive detection performance.

SecureFL-IDS represents a step toward practical privacy-preserving security systems for cloud environments. The open-source implementation and comprehensive evaluation provide a foundation for future research and real-world deployment. As cloud adoption continues to accelerate and privacy regulations tighten, federated learning approaches like SecureFL-IDS will become increasingly critical for securing modern distributed systems while respecting data sovereignty and user privacy.
